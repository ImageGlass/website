What's New in ImageGlass 9.4

Security & Core Improvements

This release is built on .NET 10, delivering faster performance and long-term stability. We have upgraded libwebp to v1.6 for improved WebP support, and updated Magick.NET to v14.10.1, resolving several security advisories:

  • CVE-2025-53015
  • CVE-2025-55004
  • CVE-2025-55154
  • CVE-2025-55298
  • CVE-2025-62594

Other refinements include:

  • The "Set default photo viewer" function now respects per-user installations.
  • GIF playback improvements, with a default 10ms frame delay applied when none is specified.
  • Quick Setup, Settings, and About windows now follow system font sizes.
  • Dark mode has been polished for native controls, making the interface more consistent and easier on the eyes.

Smarter SVG and Format Support

ImageGlass 9.4 enhances SVG support by showing the relative paths of embedded images when using WebView2. We've also expanded default format recognition – .HIF is now supported out of the box to keep pace with modern camera standards.

Other Improvements and Fixes

We have fixed several issues reported by the community to make ImageGlass more stable:

  • Drag-and-drop of gallery thumbnails now works correctly after renaming images.
  • Individual color channel views render properly in all scenarios.
  • Multipage TiffG4 files with .FAX extensions can now be printed and paged through without issue.
  • Rotating an image no longer causes stretched or cropped displays when switching view channels.

A full list of changes and bugfixes is available in the release notes.
