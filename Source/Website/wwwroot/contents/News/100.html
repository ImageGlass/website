Announcing ImageGlass 9.5

I am pleased to announce the release of ImageGlass 9.5. This is a minor update that includes a few community-requested features and bugfixes.

You can help this project by making a donation or purchasing from Microsoft Store:

##IMAGEGLASS_STORE##

Improvements

  • Updated Magick.NET to version 14.13.0
  • DPI Information: You can now add DPI data directly in the image information tags in Settings > General, kudo to @Poley4229.
  • Sibling Directory Auto-switch: A new setting that allows ImageGlass to automatically switch to the next sibling directory once you reach the end of the current image list in Settings > Image, kudo to @ThingOfNull.

Bugfixes

  • Window Scaling: Fixed an issue where the app window would progressively shrink each time it was opened on a secondary monitor.
  • Search Integration: Resolved an error that occurred when attempting to open ImageGlass from Windows Search results.

A full list of changes and bugfixes is available in the release notes.

Roadmap Update: Version 9 Maintenance Mode

In line with the ImageGlass Roadmap Update - 2026, version 9 has now officially entered maintenance mode.

From this point forward, I will focus on providing bugfixes and stability updates for the version 9 branch. No further new features will be added to this version as development efforts shift toward the upcoming ImageGlass 10. This ensures a stable experience for current users while the next generation of the app matures.
