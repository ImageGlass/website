# Announcing ImageGlass 9.6

I am pleased to announce the release of ImageGlass 9.6. Version 9 is in maintenance mode, so this is a focused stability update: an updated imaging engine, a higher default cache limit for large photos, and fixes for a few reported format and tool issues.

**⚠️ Security Alert: Fake Repositories and AI Threat Mitigation**

Automated malicious campaigns are actively deploying AI tools to impersonate trusted software. They stand up fake GitHub profiles and standalone Gists designed to trick users into downloading compromised packages. Please enforce the following verification steps on every installation:

- **Only use official channels**: Always download ImageGlass directly from the official website ([https://imageglass.org](https://imageglass.org)). Never download binaries from third-party mirrors, unverified GitHub forks, or standalone GitHub Gists.
- **Verify the repository source:** The only authentic spaces for this project on GitHub are the official [d2phap/ImageGlass](https://github.com/d2phap/ImageGlass) repository and the [ImageGlass Organization](https://github.com/ImageGlass). Any other profile or fork promising 'portable patches', 'extended releases', or alternative mirrors is completely unauthorized and highly likely to contain malware.
- **Check the URL**: Double-check your browser address bar to ensure you are not visiting a typosquatted domain.

If you identify an unauthorized mirror, submit a report immediately to help keep the community safe.
:::

## Improvements

- Updated Magick.NET to version 14.16.0.
- **Larger Images Stay Cached**: The default value of `ImageBoosterCacheMaxDimension` is now 9000, so high-resolution photos are cached and browsed smoothly without having to change a setting first.

## Bugfixes

- **Multi-frame HEIC**: Fixed a Magick MaxItems policy limit that prevented multiframe HEIC files from opening.
- **JXL Format**: Resolved an issue where certain JPEG XL images failed to load.
- **Crop Tool**: Fixed the Crop tool being unable to select the whole image after an edit was applied.

A full list of changes and bugfixes is available in the [release notes](https://github.com/d2phap/ImageGlass/releases/tag/9.6.0.801).

## What Is Next for ImageGlass 10

ImageGlass 10 has reached its [Release Candidate stage](https://imageglass.org/news/announcing-imageglass-10-rc-102). It is built from the ground up on a modern .NET stack and the Avalonia UI framework, running natively on Windows, macOS, and Linux from a single codebase, and it brings a refreshed Fluent 2 design, a complete native Settings interface, a new Quick Setup experience, and hardened plugin security.

Alongside the RC, I have published the [ImageGlass 10 Release Plans](https://imageglass.org/news/imageglass-10-release-plans-103). That post explains how the app will be offered at its stable release: ImageGlass Classic stays free and open source under the GNU GPLv3, and an optional ImageGlass Pro edition will add an advanced workflow and administration layer for people and organizations who want it. It also covers the move from the MSI installer to MSIX and ZIP packages on Windows, and it points to an open discussion where your feedback is welcome before the final release.

Version 9 keeps receiving bugfixes and stability updates in the meantime, so you can stay on it for as long as it suits your workflow.
