## What's New in ImageGlass 9.3

### No More .NET Desktop Runtime Needed
ImageGlass is now completely self-contained. That means you **no longer** need to install the .NET Desktop Runtime to run the app.

**Minimum system requirements**:
- Windows 10/11 64-bit, version 1809 (build 17763) or later
- _(Optional)_ [WebView2 Runtime 64-bit v119.0.2151 or later](https://go.microsoft.com/fwlink/p/?LinkId=2124703)
  + **Note:** Without WebView2 Runtime, certain features (e.g., Settings window, SVG rasterization,...) are unavailable.

This change also allows us to upgrade the app to .NET 9 which is more robust and performant.


### Explorer Sort Order V2 – More Aligned with Your Workflow
ImageGlass now works more closely with File Explorer, respecting the exact sort order you've set — including:
- All column-based sort types (e.g., name, date, type, rating)
- Support for `.search-ms` saved searches
- Syncing the image list with Explorer's view

**Note:** The related File Explorer window needs to remain open (it can be minimized) for this to work properly.

This update should make browsing and navigating large folders more predictable and consistent, especially for those who rely on specific sorting workflows.


### Expanded Format Support
- New formats supported: `.SVGZ`, `.JXR`, `.HDP`, and `.WDP`.
- Live Photo support: View motion content in JPEGs from modern smartphones.
- New **"Invert Colors"** feature: A quick way to flip colors for better contrast or creative inspection. You can access it via _Main Menu_ > _Image_ > _Invert colors_, or use hotkey <kbd>Ctrl+I</kbd>.


### Other Improvements and Fixes
We've made several enhancements to improve your experience:
- Upgraded to .NET 9 and Magick.NET 14.6
- Improved support for HEIC files with updated internal settings
- The Frame Navigation tool now remembers its state between sessions
- More refined SVG handling when using WebView2 (checkerboard limited to image bounds)
- Various UI fixes for high-DPI/multi-monitor setups

A full list of changes and bugfixes is available in the [release notes](https://github.com/d2phap/ImageGlass/releases/tag/9.3.0.514).
