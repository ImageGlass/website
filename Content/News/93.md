## What's New in ImageGlass 9.2

### New Resize Image Tool
One of the most-requested features is finally here! The new **Resize Image** tool lets you scale images up to 16,384 pixels using the robust [PhotoSauce.MagicScaler](https://photosauce.net) library. You can select from a variety of resampling methods to ensure the perfect balance between image quality and performance.

![ImageGlass Resize Tool](https://github.com/user-attachments/assets/99e24035-8c07-40dc-bef3-85ba8a127455)

How to access:
- Go to _Main Menu > Tools > Resize Image_
- Use the shortcut: <kbd>Alt+R</kbd>

**Note**: Like other editing tools, resized images are saved without metadata (e.g., EXIF data).


### Crop Image Tool 2.0: Pixel-Level Precision
User feedback has been central to this upgrade. The revamped **Crop Image** tool brings pixel-level precision while making the interface more intuitive and responsive.

![ImageGlass Crop Tool](https://github.com/user-attachments/assets/e327fd60-461e-41d0-83fc-5abd84cfea8c)

Improvements include:
- Cursor updates for better clarity while cropping.
- Cropping selections align exactly with the image source.
- Zooming and panning won't disrupt your selection.
- Selection areas can now be resized from any edge or corner.
- Snap-to-pixel precision for fine control over cropping boundaries.
- Selections remain active even when clicking outside them.
- Default selections respect aspect ratios and crop settings.


### WebView2 Runtime: Now Optional
With ImageGlass 9.2, the WebView2 Runtime is now an optional feature. If it's not installed, ImageGlass will bypass the **Quick Setup** dialog and notify you with a warning popup, complete with a download link for missing components.

This change gives you more flexibility, especially in environments where WebView2 isn't available or needed.

**Note**: Without WebView2 Runtime, certain features (e.g., Settings window, SVG rasterization,...) are unavailable.


### Support for Larger Image Dimensions
ImageGlass now supports images larger than 16,384 pixels by leveraging Direct2D Software Rendering. Unlike previous versions that automatically scaled down large images, version 9.2 allows you to view these files in their full resolution, preserving every detail.


### Enhanced Custom Actions
In ImageGlass, you can create a custom action and assign it to a toolbar button or a tool in Tools menu.

New capabilities include:
- Use app protocols (e.g., `ms-photos:viewer?fileName=<file>`) to integrate other apps seamlessly.
- Assign hotkeys to custom toolbar buttons for quicker access.

**New API**: The `IG_ApplySettings(string json)` API enables you to apply settings directly from a JSON configuration, making it easier to tweak and apply preferences programmatically.

![ImageGlass custom toolbar button](https://github.com/user-attachments/assets/a05ebaf6-251b-4e8d-9d19-08e92d04b6f0)


### Other Improvements
We've made several enhancements to improve your experience:
- Auto-sorts new images based on current sort order.
- Slideshow intervals now support less than 1 second.
- Added custom zoom for slideshows.

This version also includes bug fixes, such as improved hotkey support for non-English languages.
